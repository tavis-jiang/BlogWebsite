5. 设 (DS)=2000 H, (BX)=0100 H, (SI)=0002 H, (20100 H)=12 H, (20101 H)=34 H, (20102 H)=56 H, (20103 H)=78 H, (21200 H)=2 AH, (21201 H)=4 CH, (21202 H)=B 7 H, (21203 H)=65 H。试说明下列各条指令执行完后，AX 寄存器的内容。

- **(1) MOV AX, 1200 H**
    
    - **结果**：$AX = 1200H$
        
    - **解析**：立即寻址，将十六进制数 1200 直接送入 AX。
        
- **(2) MOV AX, [1200 H]**
    
    - **结果**：$AX = 4C2AH$
        
    - **解析**：直接寻址。物理地址 = $20000H + 1200H = 21200H$。该地址开始的一个字为 $2A$（低位）和 $4C$（高位）。
        
- **(3) MOV AX, BX**
    
    - **结果**：$AX = 0100H$
        
    - **解析**：寄存器寻址，将 BX 的内容（0100 H）送入 AX。
        
- **(4) MOV AX, [BX]**
    
    - **结果**：$AX = 3412H$
        
    - **解析**：寄存器间接寻址。物理地址 = $20000H + 0100H = 20100H$。内容为 $12H$ 和 $34H$。
        
- **(5) MOV AX, [BX+SI]**
    
    - **结果**：$AX = 7856H$
        
    - **解析**：基址变址寻址。物理地址 = $20000H + 0100H + 0002H = 20102H$。内容为 $56H$ 和 $78H$。
        
- **(6) MOV AX, 1100 H[BX]**
    
    - **结果**：$AX = 4C2AH$
        
    - **解析**：寄存器相对寻址。物理地址 = $20000H + 0100H + 1100H = 21200H$。内容为 $2A$ 和 $4C$。

29. 8086 中断向量表（IVT）的作用是什么？它是如何组织的？

- **作用**：中断向量表是存放所有中断服务程序入口地址（中断向量）的一个特定存储区域。 当硬件或软件中断发生时，CPU 根据中断类型码在该表中查找对应的程序入口，实现程序的跳转。
    
- **组织方式**：
    
    - 存放于内存最低端的 **00000 H ~ 003 FFH** 区域，共 1024 字节。
        
    - 每个中断类型占用 **4 个字节**（2 个字节存放偏移地址 IP，2 个字节存放段地址 CS）。
        
    - 共有 256 个中断项（0 ~ 255）。
        

32. 简述 8086 CPU 响应中断的过程。

当 CPU 响应中断（如执行 `INT n` 指令或接收到外部中断请求）时，会自动执行以下硬件操作：

1. **取中断类型码**：获取中断类型号 $n$（若是硬件中断由接口提供，若是 `INT n` 则由指令提供）。
    
2. **保护现场（压栈）**：
    
    - 将标志寄存器 **PSW (FLAGS)** 压入堆栈。
        
    - 将当前代码段寄存器 **CS** 压入堆栈。
        
    - 将当前的指令指针 **IP**（指向中断指令的下一条指令）压入堆栈。
        
3. **关中断**：将标志寄存器中的 IF（中断允许标志）和 TF（陷阱标志）清零，以禁止在处理该中断时响应其他可屏蔽中断。
    
4. **计算并取出向量**：计算中断向量在表中的地址（$n \times 4$），从该地址取出 **IP** 和 **CS**。
    
5. **转移执行**：将取出的 IP 和 CS 送入对应寄存器，CPU 开始执行中断服务程序。1. **地址线与数据线：**
- (1) 2 K×16：**11 条**地址线 ( $2^{11}=2K$ )，**16 条**数据线 。
- (2) 64 K×8：**16 条**地址线 ( $2^{16}=64K$ )，**8 条**数据线 。
- (3) 16 M×32：**24 条**地址线 ( $2^{24}=16M$ )，**32 条**数据线。
- (4) 4 G×4：**32 条**地址线 ( $2^{32}=4G$ )，**4 条**数据线 。

2.  **芯片组成计算：**
- 芯片数量：$(16K \div 1024) \times (8 \div 1) = 16 \times 8 = \mathbf{128}$ **片** 。
- 片内寻址：$1024$ 位需要 **10 位** 地址线（$A_0 \sim A_9$） 。
- 片选信号：剩余 **6 位**（$16 - 10 = 6$）参与组合产生片选信号 。

3. **64 K×8 存储器设计：**
- 采用 EPROM 2764（8 K×8）：需要 $64K \div 8K = \mathbf{8}$ **片** 。
- 地址范围 40000 H~4 FFFFH 对应地址总线 $A_{19} \sim A_{16}$ 为 `0100` 。
- 地址连接：$A_0 \sim A_{12}$ 接芯片地址线；$A_{13} \sim A_{15}$ 接 74 LS 138 的译码输入端；$A_{16} \sim A_{19}$ 经过逻辑门接 74 LS 138 的使能端（$E_1, \bar{E_2}, \bar{E_3}$） 。
